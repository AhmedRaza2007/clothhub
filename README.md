# Clothhub

Clothhub is a Pakistani fashion storefront built with React and Vite. It showcases clothing collections, product details, and an interactive fashion experience.

## Download the app

- **iOS:** [Download Clothhub on the App Store](https://apps.apple.com/us/app/clothhub/id6823178759)
- **Android:** [Get Clothhub on Google Play](https://play.google.com/store/apps/details?id=com.clothhubapp)

## Features

- Browse fashion collections and featured products
- Product details, shopping cart, and wishlist
- Interactive wardrobe and 3D fashion showcases
- Virtual try-on experience
- Responsive storefront layout

## Run locally

Requirements: Node.js 20.19+ (or 22.12+) and npm.

```bash
npm install
npm run dev
```

Vite prints the local development URL after the server starts.

## Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build in `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |
